## Sobre

Este wiki é um catálogo estruturado de todos os repositórios públicos da conta `lucaslimacodes` no GitHub. Ele foi criado seguindo o padrão de [llm-wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) do Andrej Karpathy: um conhecimento persistente e interligado, gerado por LLM, que se mantém atualizado e serve como camada de síntese entre o owner e suas fontes brutas (neste caso, os próprios repositórios).

## Como usar

- **Visão geral:** leia este README.md.
- **Catálogo completo:** veja [index.md](./index.md) — todos os repositórios listados com descrição, linguagem, data de atualização e link.
- **Detalhes de um repositório:** cada repo tem sua própria página em `repos/<nome-do-repo>.md` com descrição, linguagem, topics, datasheet básico e observações.
